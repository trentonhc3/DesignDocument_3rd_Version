# DesignDocument_3rd_Version
CS230

The client, The Gaming Room, is a game development company that requested the development of a game application called Draw It or Lose It. The goal in mind for development was to create a web-based version of the application. 
What I did well with designing documentation was to address technical concerns with development of a web-based version for the client’s software. For example, when relating to why the software I recommended would work best with the proposed software idea, Windows, I explained market dominance and how the operating system works on a core level.
The part I found helpful with the design document whilst developing code for the application was the details on functionality, as it allowed required understanding to create the code for the system.
How I incorporated the user’s needs within the design document was by elaborating on technical details on how it should be implemented, what programming language to use, and overall technical detail. It is important to understand the needs of the user whilst designing a product because if a product you design does not fit the needs of the client, you will end up wasting resources and having to redo it, and it also keeps a standard to follow whilst developing.
	How I would improve the work after looking over would be to refine what details are explained. For example, I could’ve just said that Windows has the most development tools compared to other platforms instead of adding each IDE and whatnot to that sentence.
How I approached the software design was a research approach, by researching information relating to implementation to a web-based application, and using knowledge already gained, and knowledge from research into the design.
I think analysis of the request from a research perspective is the best way to do software design because it allows you to use all resources to make sure the document is understandable, logical, and correct. For most software applications, I feel like you should always follow this approach when creating most things on your computer.
